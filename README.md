# DBSpeed

Application de chronométrage BMX race : lecture des temps de passage (départ, intermédiaires, arrivée) depuis un fichier Excel, calcul des temps et positions de chaque pilote (1 à 8 par manche), envoi des résultats par mail.

Stack : Netlify (hébergement + fonctions), Supabase (base de données), Resend (mails).
